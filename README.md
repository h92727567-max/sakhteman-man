# ساختمان من

اپ مدیریت ساختمان به زبان فارسی، Kotlin و Jetpack Compose (Material 3، RTL).

## دانلود APK

آخرین فایل نصب از صفحهٔ [Releases](https://github.com/h92727567-max/sakhteman-man/releases) قابل دانلود است.

1. فایل `sakhteman-man.apk` را بگیرید
2. روی گوشی باز کنید
3. اگر خواست، «نصب از منابع ناشناس» را برای همان برنامه اجازه بدهید
4. ورود آزمایشی: شماره موبایل + کد تایید `1234`

- ورود با نقش مدیر / مالک / مستأجر / نگهبان
- داشبورد صندوق و بدهکاران
- شارژ با روش مساوی، متراژ، ترکیبی، سفارشی
- واحدها، هزینه‌ها، تعمیرات
- اعلانات، رأی‌گیری، مراجعین، بسته، پارکینگ، کارکنان، گزارش
